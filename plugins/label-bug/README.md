# label-bug

Applies or removes the `bug` label on a PR or issue.

## Commands

| Command       | Example       | Description                                        |
| ------------- | ------------- | -------------------------------------------------- |
| `/bug`        | `/bug`        | Applies the `bug` label to a PR or issue.          |
| `/remove-bug` | `/remove-bug` | Removes the `bug` label from a PR or issue.        |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
