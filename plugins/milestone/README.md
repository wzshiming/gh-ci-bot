# milestone

Sets or clears the milestone of a PR or issue.

## Commands

| Command             | Example              | Description                             |
| ------------------- | -------------------- | --------------------------------------- |
| `/milestone <name>` | `/milestone v1.0.0`  | Sets the PR or issue milestone.         |
| `/remove-milestone` | `/remove-milestone`  | Clears the PR or issue milestone.       |

## Behavior

- **Milestones need to be created manually in advance**; setting a milestone that does not exist fails with a reply.
