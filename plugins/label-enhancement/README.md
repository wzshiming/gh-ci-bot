# label-enhancement

Applies or removes the `enhancement` label on a PR or issue.

## Commands

| Command               | Example               | Description                                           |
| --------------------- | --------------------- | ------------------------------------------------------ |
| `/enhancement`        | `/enhancement`        | Applies the `enhancement` label to a PR or issue.     |
| `/remove-enhancement` | `/remove-enhancement` | Removes the `enhancement` label from a PR or issue.   |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
