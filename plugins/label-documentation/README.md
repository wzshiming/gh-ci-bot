# label-documentation

Applies or removes the `documentation` label on a PR or issue.

## Commands

| Command                 | Example                 | Description                                             |
| ----------------------- | ----------------------- | ------------------------------------------------------- |
| `/documentation`        | `/documentation`        | Applies the `documentation` label to a PR or issue.     |
| `/remove-documentation` | `/remove-documentation` | Removes the `documentation` label from a PR or issue.   |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
