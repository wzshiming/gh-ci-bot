# label-invalid

Applies or removes the `invalid` label on a PR or issue.

## Commands

| Command           | Example           | Description                                       |
| ----------------- | ----------------- | -------------------------------------------------- |
| `/invalid`        | `/invalid`        | Applies the `invalid` label to a PR or issue.     |
| `/remove-invalid` | `/remove-invalid` | Removes the `invalid` label from a PR or issue.   |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
