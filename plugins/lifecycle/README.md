# lifecycle

Closes or reopens a PR or issue.

## Commands

| Command              | Example              | Description                                                       |
| -------------------- | -------------------- | ----------------------------------------------------------------- |
| `/close`             | `/close`             | Closes a PR or issue.                                             |
| `/close not-planned` | `/close not-planned` | Closes an issue as "not planned"; not available on pull requests. |
| `/reopen`            | `/reopen`            | Reopens a PR or issue.                                            |
