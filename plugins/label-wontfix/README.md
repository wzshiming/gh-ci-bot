# label-wontfix

Applies or removes the `wontfix` label on a PR or issue.

## Commands

| Command           | Example           | Description                                       |
| ----------------- | ----------------- | -------------------------------------------------- |
| `/wontfix`        | `/wontfix`        | Applies the `wontfix` label to a PR or issue.     |
| `/remove-wontfix` | `/remove-wontfix` | Removes the `wontfix` label from a PR or issue.   |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
