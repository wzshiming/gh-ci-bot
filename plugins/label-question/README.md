# label-question

Applies or removes the `question` label on a PR or issue.

## Commands

| Command            | Example            | Description                                        |
| ------------------ | ------------------ | --------------------------------------------------- |
| `/question`        | `/question`        | Applies the `question` label to a PR or issue.     |
| `/remove-question` | `/remove-question` | Removes the `question` label from a PR or issue.   |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
