# label-help-wanted

Applies or removes the `help wanted` label on a PR or issue.

## Commands

| Command               | Example               | Description                                           |
| --------------------- | --------------------- | ------------------------------------------------------ |
| `/help-wanted`        | `/help-wanted`        | Applies the `help wanted` label to a PR or issue.     |
| `/remove-help-wanted` | `/remove-help-wanted` | Removes the `help wanted` label from a PR or issue.   |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
