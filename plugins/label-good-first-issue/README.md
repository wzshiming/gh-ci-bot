# label-good-first-issue

Applies or removes the `good first issue` label on a PR or issue.

## Commands

| Command                    | Example                    | Description                                                |
| -------------------------- | -------------------------- | ----------------------------------------------------------- |
| `/good-first-issue`        | `/good-first-issue`        | Applies the `good first issue` label to a PR or issue.     |
| `/remove-good-first-issue` | `/remove-good-first-issue` | Removes the `good first issue` label from a PR or issue.   |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
