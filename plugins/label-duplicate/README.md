# label-duplicate

Applies or removes the `duplicate` label on a PR or issue.

## Commands

| Command             | Example             | Description                                         |
| ------------------- | ------------------- | ---------------------------------------------------- |
| `/duplicate`        | `/duplicate`        | Applies the `duplicate` label to a PR or issue.     |
| `/remove-duplicate` | `/remove-duplicate` | Removes the `duplicate` label from a PR or issue.   |

The label is created automatically if it does not exist (see [automatic label creation](../label/README.md#automatic-label-creation)).
